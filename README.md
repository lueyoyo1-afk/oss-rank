# OSS 开源软件榜 · OSS Rank

GitHub 开源软件的实时榜单 PWA：**安卓 / Windows / iOS / macOS 四大平台** × **日榜 / 周榜 / 月榜 / 总榜** 时间维度，外加 **Skill 分享榜**（AI 智能体技能仓库）与 **精选深评榜**（人工整理：用处 / 用法 / 注意事项）。英文描述**自动翻译成中文**（可一键关闭）。

## 使用方法

**方式一：直接打开**
用手机或电脑浏览器打开 `index.html` 即可（实时数据直接请求 GitHub，无需服务器）。

**方式二：安装为 App（推荐）**
需要一个 HTTP 服务（不能是 file:// 协议，否则无法注册 Service Worker）：

```bash
# 在本目录下任选一种
python3 -m http.server 8080
# 或
npx serve .
```

然后手机浏览器访问 `http://<你的电脑IP>:8080`：
- Android Chrome：菜单 → "添加到主屏幕" / "安装应用"
- iOS Safari：分享 → "添加到主屏幕"
- 桌面 Chrome/Edge：地址栏右侧安装图标

安装后拥有独立图标、离线可打开（应用外壳缓存），数据每 10 分钟自动刷新，切到后台暂停。

## 界面与交互

- **自绘 SVG 图标**：界面内所有图标（平台、刷新、勾选、下载、链接箭头等）均为内联 SVG，无 emoji，颜色随主题继承。
- **小抽屉选来源**：点左上角来源芯片（如「安卓应用 ▾」）滑出抽屉，四大系统平台 + Skill 分享 + 精选深评 + 我的收藏共 7 个来源，当前来源打勾高亮；选择结果记住在本机（localStorage），下次打开自动恢复。抽屉打开时**背景滚动自动锁定**（浮层开着滑不动榜单），抽屉内容过高时自身内部滚动；Esc / 点遮罩 / 点 ✕ 关闭。
- **排序小抽屉**：工具栏排序按钮（星标 / 时钟图标 + 当前方式）滑出底部小抽屉，切换「按星标 / 按最近推送」，选择同样持久化。
- **飙升榜**：排序新增「按涨星速度」——按较上次访问的星标**涨幅**排序，小仓库也能被发现；没有历史数据时给提示（下次打开后生效）。排序列、排序方式都会写进分享链接。
- **外观切换**：排序抽屉新增「外观」组——跟随系统 / 浅色 / 深色三选一，选择存本机、即时生效并同步状态栏 theme-color；「跟随系统」随手机 / 电脑的深浅色设置自动切换。
- **视图分享**：当前视图（来源 / 时间维度 / 排序 / 搜索词）实时编码进地址栏 hash，复制链接发给朋友，对方打开即还原同一视图。
- **导出榜单**：排序抽屉「导出榜单」一键把当前榜单复制为 Markdown 表格（排名 / 仓库 / 星标 / 简介），可直接粘贴进笔记或文档。
- **星标趋势与 NEW 徽标**：每次加载榜单后与上次本机快照对比——首次上榜的仓库标 **NEW** 徽标；星标有变化的显示 **↑/↓ 百分比** chip（绿涨红跌），直观看出热度走势。
- **迷你趋势曲线**：卡片星标右侧一条 42×13 的 sparkline，把最近最多 8 次访问的星标采样连成折线（涨绿跌黄），比单个百分比更能看出走势；不足 2 次采样时自动隐藏。
- **卡片小标签**：榜单卡片带**语言圆点标签**（Kotlin / TypeScript / C++ 等各自配色）与**分类标签**（图库备份 / 系统工具 / 键盘输入…），扫一眼就知道仓库是干嘛的。
- **分类筛选条**：榜单上方一排横向滚动的分类 chip（全部 / 文件·同步·备份 / 系统·工具 / 输入法·桌面…），带数量角标，点一下只看该类；与搜索、排序可叠加。
- **预览式榜单卡片**：列表只放排名、名字、星标和一行简介；整卡可点击（支持键盘 Enter / 空格），底部箭头引导。
- **详情卡片**：点卡片弹出，**限高（84vh）内部滚动**；含 GitHub 预览图（**加载中显示 shimmer 骨架，加载完成淡入，失败自动隐藏**）、完整描述、语言 / 推送 / 活跃 / 归档 / 分类信息、精选三栏深评（用处 / 用法 / 注意）、仓库 / Releases / 官网链接。**只能点右上角 ✕ 关闭**，点遮罩或按 Esc 均不关。
- **获取 / 已获取 / 有更新**：详情卡内下载按钮直接下载——**优先挑当前平台的安装包**（安卓 `.apk`、Windows `.exe/.msi`、macOS `.dmg/.pkg`），没有安装包时下载源码 zip。下载通过**隐藏 iframe 触发浏览器原生下载管理器**（不跳页、不弹新窗口、通知栏有进度、下完点通知即可安装）；跨域链接带 `download` 属性会被浏览器忽略、退化成"复制链接"，所以不用 `<a download>`。点后弹出**下载面板**：文件名、体积、进度条、`复制下载链接`、`已完成安装` 两个出口；在**微信 / QQ 内置浏览器**里直接提示「点右上角 → 在浏览器中打开」，不会假装已下载。下载记录存本机，再次打开显示「已获取」；检测到新版本显示「有更新」，点击即下载新版并更新记录。
  > 为什么进度条是"不确定态"：GitHub 的下载域名（`release-assets.githubusercontent.com` / `codeload`）**不返回 CORS 头**，网页读不到字节流，拿不到真实百分比——这是浏览器安全限制，不是偷懒。真实进度和"下完自动弹安装"需要原生能力（APK 壳）。
- **安装记录页**：来源抽屉新增「安装记录」——本机所有「获取」过的项目集中管理：版本号 / 获取时间 / **可编辑备注**（点击备注行就地输入，记「装在哪个设备 / 什么版本」），✕ 可删除记录；数据只存本机。
- **详情增强**：详情卡异步补充 **License 许可证 chip**、**最近 5 个版本**（版本号 + 发布日期）与 **README 摘要**（走 raw CDN 不占 API 限额，markdown 折叠为带标题层级的纯文本，最长 1200 字），三路信息各自缓存、失败静默跳过。
- **相关推荐**：详情底部推荐最多 4 个仓库——优先同分类，其次同语言，最后按星标补齐；点击推荐直接切换详情，不用退回去再找。
- **复制 clone 命令**：详情链接区一键复制 `git clone https://github.com/<repo>.git`，粘到终端即可拉代码。
- **搜索无结果空态**：搜不到东西时不再只有一句「没有匹配的项目」，附三个一键出口——清空搜索 / 关闭「仅看软件」/ 去看总榜。
- **首访引导**：第一次打开时在来源芯片下方浮出小提示（如何切换平台 / 来源），点「知道了」或任意处消失，只出现一次。
- **数据备份 / 恢复**：排序抽屉「数据」组可把本机**收藏 + 安装记录**导出为 JSON 文件，换设备时导入即合并（按仓库名去重，保留较新的记录）——数据不再只锁在一台设备上。
- **移动端手势**：列表顶部**下拉刷新**（松手即重新拉取，顶部显示「下拉刷新 / 松手刷新」），列表区**左右滑切换日/周/月/总榜**（横滑判定独立于纵向滚动，不误触）。
- **GitHub 登录（Personal Access Token）**：抽屉底部「账号」组粘贴 Token 即可，搜索额度 **10 → 30 次/分**、接口 **60 → 5000 次/时**；登录后显示 `@用户名 · 剩余次数`，可随时退出。推荐 fine-grained token、只勾 **Public repositories (read-only)**。Token 只存本机 localStorage、不上传任何服务器；401 失效自动清除并回退匿名。
- **PWA 增强**：新版本接管 Service Worker 后底部提示「有新版本可用 → 刷新」；manifest 增加**长按图标快捷方式**（我的收藏 / 安装记录 / Skill 分享），长按桌面图标可直达；离线时底部常驻「当前离线 · 显示上次数据」提示，恢复联网自动刷新。
- **收藏夹**：详情卡内「★ 收藏」按钮把项目收进「我的收藏」（来源抽屉「我的」分组进入）；**按已有分类分组**——优先沿用精选 / Skill 深评的原有分类，无深评的归平台名；组内按收藏时间倒序，并显示收藏时间（今天 / 昨天 / 日期 + 时分）；卡片上的 ✕ 可快速取消，收藏记录同样只存本机。
- **数据说明文字链**：页面底部原有的长段口径说明已收进「数据说明与口径」文字链（文字 + 底部下划线，不占地方的轻量样式，hover 变强调色），点击弹出同款限高模态（数据口径 / 详情卡片 / Skill 榜 / 翻译 / 限额与兜底 / 精选榜六节），同样只能 ✕ 关闭。
- **时间维度 tab**：日榜 / 周榜 / 月榜 / 总榜，在平台来源与 Skill 分享下显示（**Skill 榜同样有这四个时间维度**；精选与收藏不适用时间窗，tab 自动隐藏、「仅看软件」开关同时置灰）；窄屏下自动收起 hint 一屏放下。
- **搜索 + 过滤**：仓库名 / 关键词（含中文译文）实时搜索；「仅看软件」开关用启发式规则滤掉框架 / 库 / 桌面工具类仓库（Windows / iOS / macOS 使用独立的桌面版规则，不会误杀 DevToys 这类桌面应用）。
- **动画反馈**：切来源 / 切维度时先离场转场（旧列表向左淡出 180ms）→ 骨架屏（8 个 shimmer 占位）→ 新卡片从右错峰滑入；激活的维度 tab 弹一下（popp），来源芯片仅在**真切换来源**时弹（切时间维度不弹）。**点击任意卡片 / 按钮均有自绘弹跳反馈**（下压回弹的 tapb 动画，替代系统默认的蓝色点击高亮——已在全局将 `-webkit-tap-highlight-color` 置为透明）；点「刷新」图标持续旋转直至数据返回；抽屉左滑、排序面板底部滑入 + 遮罩淡入；按钮 / 卡片有点按反馈。全部动画包裹在 `prefers-reduced-motion` 判断里，系统开启「减弱动态效果」时自动关闭（连切换转场也直接跳过）。

## 数据口径

- **平台实时榜**：每平台合并「app 专属主题 + 泛主题」两路查询——安卓 `topic:android-app` + `topic:android`，Windows `topic:windows-app` + `topic:windows`，iOS `topic:ios-app` + `topic:ios`，macOS `topic:macos-app` + `topic:macos`；`pushed:>日期` 时间窗过滤，星标排序，取前 80。
- **Skill 榜**：合并 `topic:claude-skills`、`topic:agent-skills` 与 `claude skills in:name` 三路查询，按星标取前 80，合并 Skill 精选深评。**同样支持日 / 周 / 月 / 总榜**：时间维度下加 `pushed:>日期` 过滤（总榜不加，并合并精选条目）；限额回退快照时，快照只有总表，按推送日期过滤出对应维度，过滤后为空则回退全量。
- **翻译**：工具栏「翻译」开关默认开启，GitHub 英文描述自动译中（免费翻译通道，译文缓存本机 localStorage，7 天有效）；单次请求 **3.5 秒超时**、6 并发，只翻前 40 条；**译文未就绪时直接显示英文原文**（不再出现「翻译中…」占位），通道连续失败会冷却并整体回退英文，不影响浏览。「精选」榜为人工中文深评，不受开关影响。
- **GitHub 限额与降耗**：未登录时搜索 10 次/分钟、核心 60 次/小时；登录（PAT）后为 30 次/分钟、5000 次/小时。App 侧做了五层降耗：**① 页面缓存**（切回看过的维度直接复用、不耗额度，点「刷新」才强制重拉；缓存过期时先用旧数据顶上、再静默后台刷新，不闪骨架）；**② 上次成功数据兜底**（7 天内限额/断网时显示上次真实数据，而不是退回内置快照）；**③ ETag 条件请求**（详情类接口带 `If-None-Match`，GitHub 的 **304 响应不计入限额**，重复打开同一详情接近零消耗）；**④ 同 URL 并发去重**；**⑤ 切榜防抖**（连点/快滑只发最后一次请求）+ 1.2s 请求队列 + 加载代次竞态防护。仍限额或断网时自动切换**内置快照**（2026-10-24 生成：安卓 91 + Windows 60 + iOS 60 + macOS 60 + Skill 63 个已验证仓库，描述均已预翻译为中文）并明确提示，稍后点「刷新」重试。
