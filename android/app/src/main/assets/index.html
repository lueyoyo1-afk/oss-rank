应用更新
GitHub 登录

登录后请求会带上你的 Token：搜索 30 次/分钟、接口 5000 次/小时（未登录仅 10 次/分、60 次/时）。

还没有 Token？到 GitHub → Settings → Developer settings → Fine-grained tokens 新建， 权限只勾 Public repositories (read-only) 即可。Token 只保存在本机 localStorage，不上传任何服务器，可随时在 GitHub 撤销。
云同步

把收藏与安装记录同步到一个私密 Gist：换手机、清数据前备份、多设备保持一致。首次同步自动创建，之后增量覆盖。合并策略与本地备份一致——同一仓库保留较新的一条。

Token 复用「GitHub 登录」里保存的 Token（只存本机）。注意：细粒度 Token 无法访问 Gist，若报 403/404，请到 Settings → Developer settings → Personal access tokens (classic) 新建一个只勾 gist 权限的经典 Token。Gist 为私密（secret），仅持 Token 者可读写。
